# 00 · Gestão do projeto

Tudo que governa o projeto em si — não a marca, mas **como o trabalho é conduzido e registrado**.

## O que há aqui

| Item | O que é | Status |
|------|---------|--------|
| [`escopo-e-fases.md`](escopo-e-fases.md) | Escopo do contrato e fases (atual + intenção futura). | ✅ |
| [`registro-de-decisoes.md`](registro-de-decisoes.md) | Log do que já foi **decidido** e por quê. | 🚧 vivo |
| [`pendencias-e-validacoes.md`](pendencias-e-validacoes.md) | O que ainda depende de decisão/dado. Pauta de validação com o cliente. | 🚧 vivo |
| [`padroes-e-nomenclatura.md`](padroes-e-nomenclatura.md) | Regras de nome, versão e status da base. | ✅ |
| [`fontes-e-materiais-externos.md`](fontes-e-materiais-externos.md) | Índice dos originais no Google Drive (binários, contrato assinado, etc.). | 🚧 vivo |
| [`contrato/`](contrato/) | Contrato assinado (texto extraído + link ao original). | ✅ |
| [`propostas/`](propostas/) | Propostas comerciais do projeto (índice ao Drive). | ✅ |
| [`reunioes/`](reunioes/) | Roteiros, registros e transcrições de reuniões com o cliente. | 🚧 |
| [`ferramentas/`](ferramentas/) | Scripts de apoio (ex.: geração do Google Doc a partir do markdown). | ✅ |

## Onde inserir no futuro

- Nova **decisão** validada → uma linha em `registro-de-decisoes.md`.
- Novo ponto **em aberto** → uma linha em `pendencias-e-validacoes.md`.
- Nova **reunião** → arquivo em `reunioes/` no padrão `reuniao-AAAA-MM-DD-*.md`.
- Novo **original do cliente** (binário) → subir ao Drive e indexar em `fontes-e-materiais-externos.md`.
