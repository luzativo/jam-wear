## Regra

Só existe **um** Documento de Marca vigente. Ao criar nova versão: atualizar o cabeçalho (versão/data), mover a anterior para `99-arquivo/`, registrar a mudança no git e — se for um marco — no [`registro-de-decisoes.md`](../00-gestao/registro-de-decisoes.md).
