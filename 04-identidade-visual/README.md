- **Estética-âncora:** "performance silenciosa" / luxo silencioso — corte estruturado, paleta sóbria. (Documento de Marca §4.)
- **Pointer:** se for o Caminho 1, símbolo abstrato/monocromático (emblema, não ilustração realista), estética stealth/atlética, avaliar monograma **J+W**; evitar registro caça/pet. (Documento de Marca §10; pesquisa P5.)
- **⚠️ Conflito de paleta a resolver:** "marrom liver" (Guia de Visão do cliente) × recomendação de evitar marrom (pesquisa). Decidir antes de fechar a paleta.
