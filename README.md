# JAM WEAR — Base de Conhecimento da Marca

Repositório oficial e **fonte de verdade** da marca JAM WEAR — regatas masculinas premium acessíveis, de Florianópolis/SC. Mantido pela **Luzativo Estratégia e Comunicação** em parceria com os fundadores **Jener** (José Jener Sáenz Vallejo) e **Jeans** (Jeans Marco Nassi Cerna).

Aqui fica reunido, de forma estruturada e rastreável, tudo o que foi **produzido, discutido, pesquisado, validado ou está em desenvolvimento** no projeto — dos insumos do cliente às pesquisas externas, das decisões às pendências, do branding à futura identidade visual.

> **Como usar esta base:** comece sempre pelo README da pasta que te interessa — cada um explica o objetivo da pasta, o que ela guarda, o status dos materiais e onde inserir conteúdo novo. O documento vivo mais importante do projeto é [`02-branding/documento-de-marca.md`](02-branding/documento-de-marca.md).
